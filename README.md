
# ✈️ PilotAI

Your personal browser-based AI experiment.

## Features
- Dark green interface
- Custom jet branding
- Chat history
- Train PilotAI with your own text
- Browser-based memory
- No backend
- No API keys
- GitHub Pages compatible

## Installation

1. Open this repository on GitHub.
2. Upload index.html and README.md.
3. Open Settings.
4. Select Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main.
7. Select /(root).
8. Press Save.

## Website

https://ukubot14-maker.github.io/PilotAI/

## Privacy

Chats and custom training are stored in browser localStorage.

They do not automatically transfer between devices.

## Important

PilotAI currently uses a small trigram language model,
not a large-scale reasoning model.
